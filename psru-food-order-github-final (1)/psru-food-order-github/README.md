# PSRU Food Order

ระบบสั่งอาหารออนไลน์ภายในมหาวิทยาลัยราชภัฏพิบูลสงคราม

## รายละเอียดโครงการ
ระบบช่วยให้นักศึกษาและบุคลากรสามารถดูร้านอาหาร ดูเมนู เลือกอาหาร สั่งอาหาร และติดตามสถานะคำสั่งซื้อได้ ส่วนร้านค้าสามารถดูคำสั่งซื้อและปรับปรุงสถานะการเตรียมอาหารได้

## โครงสร้างโปรเจกต์

```text
PSRU-Food-Order/
├── client/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── js/
│       ├── script.js
│       └── tailwind-config.js
├── database/
│   └── database.sql
├── docs/
│   └── README.md
└── README.md
```

## เทคโนโลยี
- HTML
- CSS
- JavaScript
- Tailwind CSS configuration
- MySQL database schema (เบื้องต้น)

## วิธีทดลองระบบ
เปิดไฟล์ `client/index.html` ด้วยเว็บเบราว์เซอร์

## หมายเหตุ
เวอร์ชันปัจจุบันเป็นส่วน Frontend ของระบบ และมีไฟล์ `database.sql` สำหรับโครงสร้างฐานข้อมูลเบื้องต้นตามแบบจำลองของโครงงาน
